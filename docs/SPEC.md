# いもーとコントロールダンディ — 企画・仕様書 v0.2

> 一行：**巨大な妹「ロロ」を遅刻させずに学校に送り届ける。兄はロックオンで投げられる弾、妹は歩くだけで街が壊れる。**
> パイロット版：7〜8分。誰でも初見でほぼクリア。笑いは「ギャップ」で取る。

---

## 0. 目的（なぜ作るか）

1. **バズる**：巨大ロボの重厚感・特撮感 × 可愛い女の子、のギャップ。会話ADV的な妹とのやり取りと、巨大ロボ空想科学シューティングの迫力のミックス。
2. **速く作る**：AI と既存アセットの流用で、速い割に良い見た目でそこそこ遊べる。
3. **安く作る**：アセットは無料優先。AI 自作でトークンやり直しコストが嵩むなら数千円までの購入は可。

## 1. 体験の柱（迷ったらここに戻る）

1. **妹が常に画面にいる**。肩上でも地上でも、カメラは妹を画面内に保つ。「妹が心配で目を離せない兄」という設定とゲーム性を一致させる。
2. **ロックオンしてボタン**。操作は楽、絵は派手。パンツァードラグーン／オメガブースト式の爽快感。
3. **子どもの仕草が大破壊**。スキップ・靴飛ばし・泣く、が巨大ロボの必殺技に相当する。

参考：ギガンティックドライブ（構図・アングル）、地球防衛軍（巨大な物が来る感覚）、パンツァードラグーン（ロックオンとカメラ）。

## 3. キャラ仕様

### 3.1 兄（プレイヤー、少年）

**肩上（基本状態）**
- 溜め投擲：A を押すとサイト（照準）が出る。マウス／視点でサイトを敵に重ねると順にロックオン（最大 6）。離すと妹が兄を掴んで投げ、ロック順に着弾→爆発、最後の敵から妹の肩へ自動帰還（1〜2 秒）。帰還中も妹が画面に入る。
- まとめてロックするほどスコア倍率とクールダウン短縮。
- 妹への指示：W 前進 / A D 旋回 / 1・2・3 で技。指示は兄が吹き出しで喋る（右へまわれ／左へ回れ／ロロップだ！／蹴れ！／泣け！／オレを投げろ！）。
- 行き先は ▼ で示す（今は学校）。サイトで ▼ をロックして離すと「あそこへ行け！」＝妹がそちらへ向かう。
- B で飛び降り。

**地上（薄い）**
- 走る・ジャンプ・単発パンチ（自動ロックオン）。
- カメラは兄中心オービットだが、妹の方向へゆるく引き戻される。
- B でどこからでも肩へ飛び乗る（ジャンプ即時、1秒演出）。
- 無敵。被弾はよろけのみ。

**見た目**
- Seed-san を素体のまま。学ラン VRM が入手できたら差し替え。

### 3.2 妹「ロロ」

- 身長 60m。小学生。白 T シャツの胸から腹に縦書きの大きな「ロロ」ロゴ。
- 歩行：子どもの行進風（腕をピンと伸ばして大振り、大股）。1歩ごとにシェイク＋重低音。
- 被弾で「んー…」と 0.5 秒減速。嫌がりゲージは廃止。
- **技（クールダウン制）**
  - スキップ：周囲の敵を手足で薙ぐ（近距離全方位）。約 8 秒
  - 靴飛ばし：前方直線を貫く。建物も壊れる。約 12 秒
  - 泣く：全敵 5 秒スタン。約 30 秒。遅刻間近の救済にも
- **表情（イベント駆動、VRM プリセット）**：普通 / にっこり（技・コンボ）/ おどろく（被弾）/ 泣く（技）/ こわがる（残り 1 分）/ 校門「いってきます」
- 妹はつぶやく（音声は 7 節）。

### 3.3 敵（街を守る側：警察・自衛隊・政府）

| 敵 | 区間 | 行動 | 倒し方 |
|---|---|---|---|
| パトカー | 1〜 | 道を塞ぐ、サイレン | 踏まれる、投擲 1 発 |
| 戦車 | 2〜 | 砲撃で妹を減速 | 投擲 2 発、靴飛ばし |
| 戦闘機（ブルーインパルス、入間基地から） | 2〜 | 編隊 4〜6 機で高速飛来。色違いのカラフルなスモークを引く。妹の前を横切る→後ろへ抜ける→また前へ、のパスで「敵セット」演出。ミサイルで妹を減速 | 投擲（主な相手）、スキップ範囲外 |

- 全員コミカル。人は必ず脱出（パイロットはパラシュート）。
- 敵パス・編隊・スモーク色は `config/waves.ts`。

### 3.4 コンボ・スコア
- 複数ロック着弾「◯機まとめ！」、パトカー同時踏み「◯台まとめ潰し！」。演出用、クリア条件には影響しない。

## 4. 操作（PC 主体。スマホは仮想パッド）

| 入力 | 地上（兄） | 肩上 |
|---|---|---|
| WASD | 兄の移動（カメラ基準） | 妹：W 前進、A D 旋回 |
| マウス | カメラ（兄中心、妹へ弱い引き戻し） | カメラ（妹の頭中心）。溜め中はサイト |
| A（Space / 左クリック） | パンチ（自動ロックオン） | 押して溜め→サイトでロック→離して投擲 |
| B（Shift / E / 右クリック） | 肩へ飛び乗る | 飛び降りる |
| 1 / 2 / 3 | — | スキップ / 靴飛ばし / 泣く |
| Esc / Tab | 調整パネル | 調整パネル |

- 音声命令（急げ・スキップ・止まれ・右・ここを目指せ）は v0.3。同じ命令名でキーを先に作る。

## 5. カメラ・演出

- 肩上：妹の頭を中心にオービット。横や後ろに回すと妹の横顔・正面が見える。少し望遠。
- サイト：溜め中はマウスでサイト自体が画面内を動き、画面端に寄るとカメラがその方向へ押されて回る（パンツァードラグーン式）。
- 投擲中：当面カメラは変えない（肩上のまま）。兄は 1 体目までベジェ曲線で回り込み、2 体目以降は直線。状況に応じた俯瞰・主観への切替は後で検討（CAMERA.thrown.enabled）。
- 地上：兄の腰の高さ、妹が画面に収まらない迫力。妹方向への弱い引き戻し。
- 乗降：1 秒の上昇/降下演出（体を突き抜けないよう外側に膨らむ）。
- 妹の一歩：シェイク＋サブベース＋砂煙。
- 校門：ローアングル固定。ED：校庭の引き。

## 8. 技術構成

- Vite + React + React Three Fiber + drei + @pixiv/three-vrm + Zustand。Rapier は必要になったら。
- 1 ユニット＝1m。妹は VRM を scale で 60m 化。肩の着地は胸ボーンからのレイキャスト。
- モデルは VRM。`public/models/custom/imouto.vrm`, `bro.vrm` を置くだけで差し替え。Esc パネルで切替。
- 服のロゴはロード時に Canvas でテクスチャに描く（VRM は触らない）。
- 公開：GitHub Pages（Actions で自動）。

---

## 9. 変更しやすさのための構造ルール

```
src/
  config/
    game.ts        # 数値は全部ここ（Esc パネルから書き換え可）
    tuning.ts      # Esc パネルの項目
    waves.ts       # 区間・敵・編隊パス・スモーク色
    skills.ts      # 妹の技（範囲・クールダウン）
    expressions.ts # 表情イベント
    voices.json    # イベント名→音声
    controls.ts    # キー割当
  entities/        # Imouto / Bro / enemies
  systems/         # camera / input / lockon / procAnim / logo / events
  scenes/ ui/
docs/SPEC.md       # この文書
```
