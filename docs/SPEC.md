# いもーとコントロールダンディ — 企画・仕様書 v0.1

> 一行：**巨大な妹を遅刻させずに学校に送り届ける。兄は仮面ライダー、妹は巨大ロボ。**
> プレイ時間3分。誰でも初見でほぼクリア。笑いは「ギャップ」で取る。

---

## 1. 体験の柱（迷ったらここに戻る）

1. **ギャップで笑わせる**
   - 兄：ライダー系ヒーロー。走り・ジャンプ・攻撃が全部大仰。毎回「トゥ！」「チェストー！」と叫ぶ。
   - 妹：巨大ロボ。ズシーン、ズシーンと歩く。腕振りはのっそり見える（実は高速）。でも中身は女の子。攻撃を「蚊に刺された」「ハエがたかる」程度に嫌がる。
2. **スケール感**
   - 地上から妹を見上げる迫力
   - 妹の肩から市街を見下ろす迫力
3. **初見クリア**
   - 難易度は「失敗しそうでしない」。緊張はさせるが落とさない。

## 2. ゲームフロー（約3分）

| 時間 | フェーズ | 内容 |
|---|---|---|
| 0:00 | タイトル | 「いもーとコントロールダンディ」＋操作説明1画面。タップ/クリックで開始 |
| 0:05 | 出発 | 家の前。兄が地上、妹が玄関からズシーンと出てくる（見上げカット）。妹「いってきまーす」 |
| 0:10〜 | Wave 1 | パトカーが道を塞ぐ。踏み潰し＆コンボ教習 |
| 1:00〜 | Wave 2 | 自衛隊車両・歩兵バズーカ。妹の「嫌がりゲージ」が上がり始める |
| 2:00〜 | Wave 3 | 戦闘機のロケット攻撃。兄の超ジャンプ迎撃が活きる |

## 3. キャラ仕様

### 3.1 兄（プレイヤー）
- 身長 1.8m。ライダー風の走り（前傾、腕を後ろに流す）。
- **アクション**（すべて自動ロックオン付き）
  - 地上攻撃：近くの敵に自動で向いてパンチ/キック。掛け声「トゥ！」
  - 超ジャンプ：ビル数階分の高さまで飛ぶ。空中で敵に向かってライダーキック。「チェストー！」
  - 遠隔攻撃：ロックオン先が遠い時は自動で遠隔（エネルギー弾など）に切替。プレイヤーは意識しない。
  - 吹っ飛ばし：パトカーを殴ると妹の進路上に吹っ飛ぶ（**コンボの仕込み**）
- 妹に乗る/降りる：妹の足元に近づいて乗るボタン→自動で肩まで登る（演出でジャンプ登り）。降りる時は飛び降り。
- 無敵。攻撃を受けるとよろける程度（初見クリア方針）。

### 3.2 妹
- 身長 60m 前後（校舎3〜4階建てより明確に大きい）。
- 歩行：基本オート前進。速度は遅く見えるが、1歩で道路の車数台分進む。1歩ごとに画面シェイク＋重低音。
- **嫌がりゲージ**（0〜100）
  - 敵の攻撃を受けると上昇。パトカー<バズーカ<ロケット。
  - 50超：「んー…」と歩みが遅くなる（速度×0.7）。
  - 100：立ち止まって「もう！」と嫌がりモーション（頭を振る、腕を振り回す→周囲の敵が勝手に吹き飛ぶ）。約3秒足止め後ゲージ0にリセット。
  - 時間経過で自然減少。**兄が敵を減らすと上がらない＝露払いの意味。**
- 妹の攻撃（兄が肩上で指示）
  - 踏みつけ：進路上のものは歩くだけで踏み潰す。
  - 張り手：横方向の敵を薙ぐ。のっそり振るが当たり判定は広い。「えいっ」
  - 払い：空中の敵（戦闘機）を手で払う。
- 妹は喋る：つぶやき音声（後述）。

### 3.3 敵（街を守る側）
| 敵 | Wave | 行動 | 妹への影響 | 倒し方 |
|---|---|---|---|---|
| パトカー | 1〜 | 道を塞ぐ、サイレン | ほぼ無し（踏まれるだけ） | 踏み潰し、兄の攻撃で吹っ飛ぶ |
| 自衛隊車両 | 2〜 | 砲撃 | ゲージ小 | 兄の攻撃、妹の張り手 |
| 歩兵バズーカ | 2〜 | 遠くから撃つ | ゲージ小 | 兄の遠隔 |
| 戦闘機 | 3 | 上空からロケット | ゲージ大 | 兄の超ジャンプ、妹の払い |
- 全員コミカル。爆発は派手だが人は必ず脱出パラシュート等で無事（全年齢）。

### 3.4 コンボ
- パトカーが妹の足元で**同時に複数**潰れると「◯台まとめ潰し！」表示＋スコア。
- 兄がパトカーを吹っ飛ばして進路上に集める→妹が踏む、が狙い筋。
- スコアは演出用。クリア条件には影響しない。

## 4. 操作（PC / スマホ共通思想：移動＋2ボタン）

| 入力 | 地上（兄） | 妹の肩上 | 空中 |
|---|---|---|---|
| WASD / 左スティック | 兄の移動 | 妹の進行方向指示（左右のみ有効、前は加速指示） | 空中制御 |
| ボタンA（Space / 右下） | 攻撃（自動ロックオン）。長押しで超ジャンプ | 妹の攻撃指示（対象は自動選択：横→張り手、上→払い、前→踏みつけ強調） | 空中攻撃 |
| ボタンB（Shift / 左下） | 妹に乗る（足元にいる時） | 降りる | — |

- ロックオンは常時自動。プレイヤーは方向とタイミングだけ決める。
- スマホ：左に仮想スティック、右にA/B。縦持ち非対応、横持ち固定。
- **操作説明はタイトル1画面と、初回だけ画面内ヒント**（「Aで攻撃」「足元でBで乗れる」）。

## 5. カメラ・演出

- **地上時**：兄の背後、やや低め（腰の高さ）から。妹が画面に収まりきらない。歩くたびに揺れ。FOV広め（75〜85）。
- **肩上時**：妹の肩後方から街を見下ろす。パトカーが豆粒。FOVは少し狭めて望遠っぽく高さを強調。
- **乗降時**：カメラが一気に上昇/降下する1秒演出（ここが一番「デカい」を感じる瞬間）。
- 妹の一歩：シェイク＋サブベース＋地面にヒビ or 砂煙。
- 校門シーン：カメラを校門の高さに固定し、妹の足がまたいでいくのを下から見上げる。
- 授業シーン：校庭の引き絵。体育座りの妹の頭が校舎の屋根より上。

## 6. 音声

| 種類 | 例 |
|---|---|
| 兄 掛け声 | トゥ！ / チェストー！ / せいっ！ / 行くぞ！ / ふぅ…（ED） |
| 妹 つぶやき | いってきまーす / んー… / いたっ / なんかいる… / もう！ / えいっ / いってきます（校門）|
| 妹 授業 | はーい（出席） |
| 敵 | 「止まりなさーい！」（拡声器）、警報 |

**制作方針**
- **VOICEVOX**（無料、商用利用可、キャラ別クレジット表記要）で全部作る。
  - 兄候補：青山龍星 / 玄野武宏（叫び系が合う）
  - 妹候補：四国めたん / 春日部つむぎ（ややのんびり系）
- 妹の声はピッチを少し下げ、リバーブ強め＋ローパスで「巨大さ」を出す。掛け声は逆にドライで軽快に（ギャップ）。
- 音声はすべて `public/audio/voice/*.mp3` に置き、`voices.json` で「イベント名→ファイル」を対応付ける。**差し替えは JSON 編集のみで完結させる。**
- 品質を上げたい場合は後から人間収録 or 有料TTS（ElevenLabs等）に差し替え。構造は変えない。

## 7. 難易度設計（初見クリア保証）

- 制限時間 3:00 に対し、妹が一度も止まらなければ約 2:10 で到着。**50秒のマージン**。
- 嫌がりゲージMAXの足止めは1回3秒。完全放置でも4〜6回程度＝到着ギリギリ。少しでも兄が動けば余裕。
- 残り30秒を切ると妹が「急がなきゃ」と自発的に速度アップ（見えない救済）。
- 遅刻した場合：校門で先生に叱られる妹（巨大なのに縮こまる）→リトライ。これも笑いなので失敗体験は軽い。

## 8. 技術構成

- **Vite + React + React Three Fiber + drei + @react-three/rapier + Zustand**
- 1ユニット＝1m。シーン全体を原点付近に置き、妹は `scale` で巨大化（座標を巨大にしない）。
- カメラ near/far を絞る（near 0.5 / far 600 程度）。足りなければ `logarithmicDepthBuffer`。
- 影：DirectionalLight のシャドウカメラを妹全体が入るサイズに。`normalBias` で調整。
- 物理：Rapier `lengthUnit=1`。兄は `ccd` 有効。妹はキネマティック（物理に押されない）。
- モデル：初期はプリミティブ（カプセル＋箱）で全部作る。**モデル差し替えは最後**。VRoid→Mixamoで妹、兄はMixamo既製。
- ブラウザ配布（itch.io HTML5）。

## 9. 変更しやすさのための構造ルール

```
src/
  config/
    game.ts        # 制限時間、道の長さ、妹の速度、ゲージ閾値など数値は全部ここ
    waves.ts       # ウェーブ定義（開始秒、敵種、出現位置、数）
    voices.json    # イベント名→音声ファイル
    controls.ts    # キー/ボタン割当
  entities/        # bro / imouto / enemies（1体1ファイル）
  systems/         # camera / combo / gauge / wave-spawner / audio
  scenes/          # title / stage / ending
  ui/              # HUD、仮想パッド
docs/SPEC.md       # この文書
```

- **数値・敵構成・音声・キー割当をコードから分離**。バランス調整はconfigだけで済ませる。
- エンティティはコンポーネント単位で独立。「兄の攻撃を変える」なら `entities/bro` だけ触る。
- 演出（シェイク、音）はイベント発火→systemsが受ける方式。「妹が一歩踏んだ」イベントに揺れも音も紐付く。

## 11. 制作ステップ

1. **スケール検証**：箱の妹（60m）＋カプセルの兄。乗降カメラ演出だけ実装。見上げ/見下ろしで「デカっ」となるか確認。ここで笑えなければカメラを詰める。
2. **一本道＋妹オート歩行＋制限時間**：何もしなくても2:10で着く状態。
3. **兄の移動・攻撃・超ジャンプ**（自動ロックオン）。
4. **パトカーWave1＋踏み潰し＋コンボ**。
5. **嫌がりゲージ＋Wave2/3**。
6. **校門・授業ED**。
7. **音声（VOICEVOX）・SE・シェイク**。
8. **スマホ操作・itch.io公開**。
9. モデル差し替え（余裕があれば）。

各ステップで必ず遊べる状態を保つ。
