# いもーとコントロールダンディ — 製品化ロードマップ v1（2026-10）

> SPEC.md は「何を作るか」、この文書は「どう製品まで持っていくか」。
> 体制：作者 1 人（ディレクター兼プロデューサー）＋ AI（実装・ツール・資料・生成 AI の段取り）。外注はしない前提。
> **お金の方針：ぎりぎりまでかけない。数千円（サブスク 1〜2 か月分など）は可。万単位は「大幅な時間短縮か品質向上が確実な時」だけ。**
> 期間はすべて目安。決まったら書き換える。

---

## 0. 目標（何をもって「名を馳せる」か）

**一行**：昭和の巨大ロボアニメの熱さ × 吾妻ひでお的な可愛さ × 現代の遊びやすさ。「巨大な妹を学校に送る」という唯一無二の設定。

| 狙う層 | 刺さる要素 | ゲームで具体的にやること |
|---|---|---|
| 横山光輝 / ジャイアントロボ OVA ファン | 巨大な物の重さ、熱血、オーケストラ＋合唱、昭和 SF の設定 | 一歩ごとの地響き、見上げ構図、描き文字（ズシーン）、ナレーション、主題歌 |
| 吾妻ひでお / レトロアニメファン | 丸い線の可愛い女の子、ギャグの間、セル画の塗り | 太い輪郭線＋2 段影、スクリーントーン風の影、表情とリアクション |
| 現代のゲームファン | すぐ分かる、気持ちいい、上達が見える | 初見でクリアできる、ランク（S〜C）で上を目指せる、リトライ即開始 |

**新しい攻略感覚の核（キャッチコピー候補）**：「**レールは妹、自由は兄**」
- 妹は決まった道を歩く＝レールシューティングの「レール」。見せ場（セット）は時間と場所で決まっているので覚えて上達できる。
- 兄はその周りを自由に動く＝アクションの自由度。肩で投げる／地上で電撃・乗る・跳ぶ、をどう組み合わせるかが攻略。
- 守る対象（妹）を自分で操縦もできる、というねじれが他に無い。

**成功の物差し（数字は仮）**
1. Steam のウィッシュリスト（発売前）1 万
2. インディイベント（BitSummit / TGS インディ / デジゲー博）に出展して試遊の列ができる
3. PV が X で拡散（10 万再生）

## 2. エンジン（ブラウザ版 → Godot の判断）

- **P0 の間はブラウザ版（今の three.js）で遊びを決める**。URL で人に遊んでもらえる、私（AI）が自分で動かして確認できる、の 2 点で試作が速い。
- **P0 の終わりに Godot で重さの試作**（数日）：60m の妹＋街＋敵だけの場面を作り、作者の PC（RTX 3080）とスマホで fps を測る。
- **判断**：Steam で売るなら Godot へ移る（ネイティブで 2〜5 倍速い、Steam 連携・コントローラ対応が楽）。移るなら P1 の頭。絵・音・声・モデル（VRM / glb）はエンジンに依存しないので、作った素材は無駄にならない。数値は src/config からそのまま持っていく。
- Godot 以降は作者の PC で動かす場面が増える（重さ確認・書き出し）。その時はローカルのセッション（`claude remote-control`）を併用する。

## 3. 絵（アートディレクション）

### 3.1 方向性（P0 で私が試作 → 作者が決める）
コード側でできる「昭和アニメ化」。モデルの出来に関係なく効くので先にやる。
- 太い黒の輪郭線、影は 2 段のベタ塗り（MToon / 自前トゥーン）
- 影の部分にスクリーントーン風の網点（画面全体の後処理）
- 描き文字：地響き「ズシーン」、爆発「ドカーン」を 2D の文字として画面に出す（ジャイアントロボ OVA・漫画の演出）
- インパクトフレーム（命中の瞬間 1〜2 コマだけ白黒反転）、集中線
- 爆煙はセル風の固まった煙、空はグラデーションの書き割り風
- 色数を絞ったパレット（昭和アニメのセル絵の具っぽい色）

### 3.2 アートバイブル（作者がまとめる。1 枚ものでよい）
- 参考画像を集めた非公開のボード（横山光輝、ジャイアントロボ OVA、吾妻ひでお、昭和アニメの背景美術）
- 「やること / やらないこと」を 5 行ずつ
- **著作権の線引き**：絵柄・空気感は参考にしてよい。キャラ・メカ・ロゴ・固有名詞は真似しない。生成 AI のプロンプトにも元作品名・キャラ名は入れない

## 4. 3D モデルの調達（ほぼ無料ルート）

絵柄の方向は SPEC 3.1 / 3.2（妹＝ななこSOS ライク＋京子ちゃんの下膨れ、兄＝バビル2世ライクの学ラン）。

**流れ（主役 2 人）**：作者の手描きラフ ⇄ ComfyUI（作者の PC）で設定画（三面図）→ 画像から 3D（Hunyuan3D-2 を ComfyUI で無料、だめなら Tripo の無料枠）→ 骨入れ（Mixamo、無料）→ VRM 化（Blender＋VRM Add-on、無料）→ ゲームへ。
詳しい手順は **docs/PIPELINE_ART.md**。

| 対象 | 作り方 | 担当 |
|---|---|---|
| **妹ロロ・兄** | 上の流れ。表情・髪揺れが要るので最終は VRM。並行して「今の VRoid モデルの描き直し＋トゥーン化」を保険として持つ（tools/vrm_textures.py） | 作者が絵と生成、私が下敷き（ポーズ）・変換・組み込み |
| 雑魚メカ（パトカー・戦車・戦闘機・ヘリ） | 作者がラフ → ComfyUI で清書 → 画像から 3D。数が多いので AI 生成向き。骨は不要（回転するだけ） | 作者＋私 |
| ボス・エネミービル | 同上。動く所だけ部品に分けて生成 | 作者＋私 |
| 怪鳥トコロス | 作者の Tripo モデル（済） | 作者 |
| 街の建物 | PLATEAU（5 章）＋コード生成＋Kenney（CC0） | 私 |

- 生成 AI の画像・3D は「作者の手描きラフ」を元にする（作者の創作が入っていることが、権利の面でも絵の個性の面でも大事）。元ネタ作品の画像を生成の入力にしない
- 学習モデル（チェックポイント・LoRA）は**商用利用可のライセンスのものだけ**使う。使ったものの名前とライセンスを docs/PIPELINE_ART.md の表に残す
- 万単位を使う候補（例外）：最後の顔の仕上げだけモデラーに数時間頼む、など。必要になったら判断

## 5. 舞台（所沢）

**所沢市は国交省 PLATEAU の 3D 都市モデル（2024 年度）が公開済み**（G 空間情報センター）。建物の形・道路が無料で手に入り、出典表記で商用利用可（公開前に利用規約を再確認）。

- 方針：**本物の所沢の道と建物の配置を使い、見た目はアニメの背景美術風に塗り直す**（写真テクスチャは使わない）。「本物の街なのにアニメ」が売りになる
- 道順：作者が「家（スタート）→ 小学校（ゴール）」の実在ルートを決める。プロペ通り（商店街）→ 駅前ビル街 → 航空公園（YS-11 など）→ 小学校、が今の区間構成と一致
- 処理（私）：PLATEAU の建物（CityGML / 3D Tiles）から、ルート周辺だけ切り出して軽い箱に変換 → ゲームに読み込むツールを作る。壊せる建物・乗れるビルの判定もそのまま使える
- ランドマーク（駅、航空公園の機体、目立つビル）は作者が写真を撮る → 写真を元に作り込む（画像から 3D、または私が箱で組む）
- 実在の店名・ロゴ（ぎょうざの満洲・山田うどん）は**許可を取るか、パロディ名に変える**。所沢市への相談（市の PR として扱ってもらえる可能性。お助けキャラの元ネタもここ）も P1 で検討

## 6. 音

### 6.1 声
- 当面 VOICEVOX（兄＝青山龍星、妹＝満別花丸。クレジット表記必須、キャラごとの商用規約を確認）。無料
- 製品で質を上げる手（安い順）：①VOICEVOX の抑揚・間の作り込み（無料）②他の商用可の音声合成（AivisSpeech など。無料〜数千円）③知人や駆け出しの声優さんに少量だけ（万単位になるので例外扱い）
- ナレーター案：区間の頭や PV で「説明しよう！」調の昭和ナレーション。レトロファンへの決め手
- 妹の声は巨大さの加工（ピッチ・残響）を後からかける

### 6.2 音楽（オーケストラ＋合唱の「風」を、ほぼ無料で）
詳しい手順は **docs/PIPELINE_MUSIC.md**。要点：
- **参考曲を分解 → 作り替え**：参考曲のコード進行・曲の構成・楽器の重ね方・リズムの型を取り出し（ここは著作権で守られにくい部分）、**メロディだけは新しく作る**（ここが守られる部分）。私がメロディの似すぎチェックを機械でかける
- 分解の道具：音声 → MIDI（Spotify の Basic Pitch、無料・私が動かせる）。作者がアップした参考曲を私が解析して、キー・コード進行・メロディの輪郭をメモにする
- 作る道具：①音楽生成 AI（Suno など。**商用利用は有料プランが必要**＝月数千円、要る月だけ契約）にメロディ・歌詞・曲調の指示を渡す ②無料のオーケストラ音源（BBC Symphony Orchestra Discover など）と無料 DAW で、私が書いた MIDI を鳴らす。①で全体を作り、②で主題の旋律を確実に自分のものにする、の組み合わせ
- **曲を少なく、主題（モチーフ）を使い回す**：主題歌のメロディを、区間曲・ボス曲・ED にアレンジ（ジャイアントロボ OVA の作り方）。目安 8〜9 曲
- 今の BGM（GiantLOLO）は仮。公開前に必ず差し替え

### 6.3 効果音
効果音ラボ（商用可・表記任意）で継続。地響き・巨大な足音など主役級の音だけは P2 で作り込む（効果音の加工・合成で自作）。

## 8. 遊び（ゲームバランス）の進め方

- **区間を「見せ場（セット）」の並びで設計**：1 区間 3〜5 個。例「戦闘機の爆撃 → 休み → 戦車隊の封鎖 → エネミービル」。何秒目に何が来るかを config/waves.ts に書く（レールシューティングと同じ作り方）
- **評価**：クリアは易しく、S ランクは難しく。タイム・街の被害・まとめ倒し・妹の被弾で採点。リトライは即開始
- **試遊の回し方**：毎週 1 回、作者が通しで遊んで「面白かった瞬間 / だれた瞬間 / 迷った瞬間」を 3 行ずつメモ → 私が数値を調整。月 1 回は他人（5 人）に遊んでもらい、横で見る（口出ししない）
- 簡単な記録（何秒でどこまで行ったか、何で詰まったか）を私がゲームに入れる

## 9. 発売・宣伝（P1 から並行）

- Steam ストアページは**縦切りができたらすぐ作る**（ウィッシュリストは時間で貯まる）。必要物：カプセル画像（ComfyUI で作者が作る）、スクショ 5 枚、ティザー PV

- イベント：BitSummit（京都・夏）、東京ゲームショウのインディ枠（秋）、デジゲー博（秋〜冬）、Steam Next Fest（年 3 回、体験版で参加）
- パブリッシャー・支援制度：インディ向けの出版社や、出版社系のクリエイター支援（例：講談社ゲームクリエイターズラボ、集英社ゲームズの支援企画など。条件・募集時期は要確認）。縦切りと PV があれば話ができる

**作者**

1. 済：昭和アニメ風の画面（墨の輪郭線・網点・色の段付け・インパクトフレーム・描き文字）。次は作者の感想で調整
