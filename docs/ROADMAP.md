# いもーとコントロールダンディ — 製品化ロードマップ v1（2026-10）

> SPEC.md は「何を作るか」、この文書は「どう製品まで持っていくか」。
> 体制：作者 1 人（ディレクター兼プロデューサー）＋ AI（実装・ツール・資料）＋ 必要な所だけプロに外注（絵・音・声）。
> 金額・期間はすべて目安。決まったら書き換える。

---

## 0. 目標（何をもって「名を馳せる」か）

**一行**：昭和の巨大ロボアニメの熱さ × 吾妻ひでお的な可愛さ × 現代の遊びやすさ。「巨大な妹を学校に送る」という唯一無二の設定。

| 狙う層 | 刺さる要素 | ゲームで具体的にやること |
|---|---|---|
| 横山光輝 / ジャイアントロボ OVA ファン | 巨大な物の重さ、熱血、オーケストラ＋合唱、昭和 SF の設定 | 一歩ごとの地響き、見上げ構図、描き文字（ズシーン）、ナレーション、主題歌 |
| 吾妻ひでお / レトロアニメファン | 丸い線の可愛い女の子、ギャグの間、セル画の塗り | 太い輪郭線＋2 段影、スクリーントーン風の影、表情とリアクション |
| 現代のゲームファン | すぐ分かる、気持ちいい、上達が見える | 初見でクリアできる、ランク（S〜C）で上を目指せる、リトライ即開始 |

**新しい攻略感覚の核（キャッチコピー候補）**：「**レールは妹、自由は兄**」
- 妹は決まった道を歩く＝レールシューティングの「レール」。見せ場（セット）は時間と場所で決まっているので覚えて上達できる。
- 兄はその周りを自由に動く＝アクションの自由度。肩で投げる／地上で電撃・乗る・跳ぶ、をどう組み合わせるかが攻略。
- 守る対象（妹）を自分で操縦もできる、というねじれが他に無い。

**成功の物差し（数字は仮）**
1. Steam のウィッシュリスト（発売前）1 万
2. インディイベント（BitSummit / TGS インディ / デジゲー博）に出展して試遊の列ができる
3. PV が X で拡散（10 万再生）

## 2. エンジン（ブラウザ版 → Godot の判断）

- **P0 の間はブラウザ版（今の three.js）で遊びを決める**。URL で人に遊んでもらえる、私（AI）が自分で動かして確認できる、の 2 点で試作が速い。
- **P0 の終わりに Godot で重さの試作**（数日）：60m の妹＋街＋敵だけの場面を作り、作者の PC（RTX 3080）とスマホで fps を測る。
- **判断**：Steam で売るなら Godot へ移る（ネイティブで 2〜5 倍速い、Steam 連携・コントローラ対応が楽）。移るなら P1 の頭。絵・音・声・モデル（VRM / glb）はエンジンに依存しないので、外注物は無駄にならない。数値は src/config からそのまま持っていく。
- Godot 以降は作者の PC で動かす場面が増える（重さ確認・書き出し）。その時はローカルのセッション（`claude remote-control`）を併用する。

## 3. 絵（アートディレクション）

### 3.1 方向性（P0 で私が試作 → 作者が決める）
コード側でできる「昭和アニメ化」。モデルの出来に関係なく効くので先にやる。
- 太い黒の輪郭線、影は 2 段のベタ塗り（MToon / 自前トゥーン）
- 影の部分にスクリーントーン風の網点（画面全体の後処理）
- 描き文字：地響き「ズシーン」、爆発「ドカーン」を 2D の文字として画面に出す（ジャイアントロボ OVA・漫画の演出）
- インパクトフレーム（命中の瞬間 1〜2 コマだけ白黒反転）、集中線
- 爆煙はセル風の固まった煙、空はグラデーションの書き割り風
- 色数を絞ったパレット（昭和アニメのセル絵の具っぽい色）

### 3.2 アートバイブル（作者がまとめる。1 枚ものでよい）
- 参考画像を集めた非公開のボード（横山光輝、ジャイアントロボ OVA、吾妻ひでお、昭和アニメの背景美術）
- 「やること / やらないこと」を 5 行ずつ
- **著作権の線引き**：絵柄・空気感は参考にしてよい。キャラ・メカ・ロゴ・固有名詞は真似しない。外注先にもこの線を伝える

## 5. 舞台（所沢）

**所沢市は国交省 PLATEAU の 3D 都市モデル（2024 年度）が公開済み**（G 空間情報センター）。建物の形・道路が無料で手に入り、出典表記で商用利用可（公開前に利用規約を再確認）。

- 方針：**本物の所沢の道と建物の配置を使い、見た目はアニメの背景美術風に塗り直す**（写真テクスチャは使わない）。「本物の街なのにアニメ」が売りになる
- 道順：作者が「家（スタート）→ 小学校（ゴール）」の実在ルートを決める。プロペ通り（商店街）→ 駅前ビル街 → 航空公園（YS-11 など）→ 小学校、が今の区間構成と一致
- 処理（私）：PLATEAU の建物（CityGML / 3D Tiles）から、ルート周辺だけ切り出して軽い箱に変換 → ゲームに読み込むツールを作る。壊せる建物・乗れるビルの判定もそのまま使える
- ランドマーク（駅、航空公園の機体、目立つビル）は作者が写真を撮る → 私か外注が作り込む
- 実在の店名・ロゴ（ぎょうざの満洲・山田うどん）は**許可を取るか、パロディ名に変える**。所沢市への相談（市の PR として扱ってもらえる可能性。お助けキャラの元ネタもここ）も P1 で検討

## 6. 音

### 6.1 声
| 段階 | 方法 |
|---|---|
| P0〜P1 | VOICEVOX のまま（今の兄＝青山龍星、妹＝満別花丸。クレジット表記必須、キャラごとの商用規約を確認） |
| 製品 | **主役 2 人とナレーターは声優に依頼**。昭和アニメの熱血演技はここが一番効く。台本は P2 の頭で確定させ、一括収録 |

- ナレーター案：区間の頭や PV で「説明しよう！」調の昭和ナレーション。レトロファンへの決め手になる
- 妹の声は巨大さの加工（ピッチ・残響）を後からかける。収録は素の声で

### 6.2 音楽（オーケストラ＋合唱）
- **曲を少なく、主題（モチーフ）を使い回す**：主題歌のメロディを、区間曲・ボス曲・ED にアレンジして使う（ジャイアントロボ OVA の作り方。少ない曲数で統一感が出る）
- 必要曲数の目安：主題歌（歌あり・合唱）1、区間 3、ボス 1〜2、タイトル・ED・リザルト 3 ＝ 8〜9 曲
- 作り方の現実解：作曲家がオーケストラ音源（サンプル音源）で作り、**合唱だけ少人数を生で録って重ねる**。フルオーケストラの生録音は数百万円規模なので、主題歌だけ一部生（弦など）にするかは予算次第
- 進め方：P0〜P1 は作者が AI 作曲などで「こういう感じ」の仮曲を作る（方向性の共有用。製品には使わない）→ P1 で作曲家を決め、まず主題歌のデモ → ティザー PV に使う
- 今の BGM（GiantLOLO）は仮。公開前に必ず差し替え

### 6.3 効果音
効果音ラボ（商用可・表記任意）で継続。地響き・巨大な足音など主役級の音だけは P2 で作り込む（外注 or 自作）。

## 7. PV

| 種類 | 時期 | 長さ | 中身 |
|---|---|---|---|
| ティザー | P1 末 | 30 秒 | 主題歌のサビ＋妹の一歩＋見上げ構図＋タイトル。ストアページと X 用 |
| 本 PV | P2 末 | 90 秒 | 昭和アニメの OP 風（ナレーション→ 描き文字のタイトル→ 遊びの見せ場→ 発売情報） |

- 撮り方：私が「PV 用カメラモード」（決めたカメラワークを再生する機能。数値は config）を作る → 作者の PC で 60fps 録画（OBS、無料）→ DaVinci Resolve（無料）で編集
- クラウドの環境では GPU が無く滑らかに録れないので、録画は必ず作者の PC

## 8. 遊び（ゲームバランス）の進め方

- **区間を「見せ場（セット）」の並びで設計**：1 区間 3〜5 個。例「戦闘機の爆撃 → 休み → 戦車隊の封鎖 → エネミービル」。何秒目に何が来るかを config/waves.ts に書く（レールシューティングと同じ作り方）
- **評価**：クリアは易しく、S ランクは難しく。タイム・街の被害・まとめ倒し・妹の被弾で採点。リトライは即開始
- **試遊の回し方**：毎週 1 回、作者が通しで遊んで「面白かった瞬間 / だれた瞬間 / 迷った瞬間」を 3 行ずつメモ → 私が数値を調整。月 1 回は他人（5 人）に遊んでもらい、横で見る（口出ししない）
- 簡単な記録（何秒でどこまで行ったか、何で詰まったか）を私がゲームに入れる

## 9. 発売・宣伝（P1 から並行）

- Steam ストアページは**縦切りができたらすぐ作る**（ウィッシュリストは時間で貯まる）。必要物：カプセル画像（イラストレーターに依頼）、スクショ 5 枚、ティザー PV
- 開発ログを X に週 1〜2 回（GIF 1 枚＋一言で十分）。妹の一歩・描き文字・兄の電撃は GIF 映えする
- イベント：BitSummit（京都・夏）、東京ゲームショウのインディ枠（秋）、デジゲー博（秋〜冬）、Steam Next Fest（年 3 回、体験版で参加）
- パブリッシャー・支援制度：インディ向けの出版社や、出版社系のクリエイター支援（例：講談社ゲームクリエイターズラボ、集英社ゲームズの支援企画など。条件・募集時期は要確認）。縦切りと PV があれば話ができる
