# 音楽の作り方（オマージュだがパクリではない、をほぼ無料で）

> 狙い：昭和の巨大ロボアニメのオーケストラ＋合唱の熱さ（ROADMAP 6.2）。お金は Suno 等の有料プランを要る月だけ（月数千円）。
> 進め方：**参考曲を分解 → 借りてよい所だけ借りる → メロディは新しく作る → 機械で似すぎチェック → 音にする**。

---

## 1. 何を借りてよくて、何を借りないか

| 借りてよい（著作権で守られにくい） | 借りない（守られる・一発で分かる） |
|---|---|
| コード進行（I–vi–IV–V 等。定番はどの曲にもある） | **メロディ**（歌の旋律、目立つ楽器の旋律） |
| 曲の構成（前奏→A→B→サビ→間奏…）、小節数 | 歌詞 |
| テンポ、拍子、リズムの型（マーチの付点、3 連のはずみ） | 一度聴いたら分かる決めのフレーズ（リフ、イントロの旋律） |
| 楽器の組み合わせ・音の重ね方（金管＋男声合唱、弦の刻み、ティンパニ） | 録音そのもの（サンプリング） |
| 雰囲気・ジャンル（昭和アニソン、マーチ、ロマン派オーケストラ） | 曲名・作曲者名をそのまま使った宣伝 |

迷ったら「メロディを鼻歌で歌って、元の曲だと分かるか」。分かるなら書き直す。

## 2. 手順

### ① 参考曲を選ぶ（作者）
- 主題歌の参考を 3〜5 曲（昭和アニソン系 2〜3、オーケストラ系 1〜2）
- 音声ファイル（mp3 / wav）をこのチャットに貼る。手元の CD 等から作者が用意したもの。**リポジトリには入れない**（著作物なので）

### ② 分解（私）
```
python3 tools/music/analyze.py 参考曲.mp3 出力フォルダ
```
- キー、テンポ、曲の区切り、コード進行（コード名と度数）、メロディの輪郭、耳コピの MIDI（full.mid / melody.mid）を出す
- 私が「借りてよい要素」と「借りない要素」を表にまとめて返す
- 精度は自動の耳コピ程度（コードは 7 割）。合成した曲で試すと、キー・テンポ・コード進行は正しく取れた

### ③ 設計図とメロディ案（私 → 作者が選ぶ）
- 構成・小節数・テンポ・キー・コード進行（参考の進行を少し変えたもの）を決める
- メロディ案を**文字で複数書く**（`docs/music/*.txt`）→ MIDI と試聴用 wav にする：
  ```
  python3 tools/music/sketch.py docs/music/theme_sketch_A.txt docs/music/out
  ```
- 作者が聴いて選ぶ・直す。直しは「ここの 3 小節目を上げて」のような言葉でよい（私が書き直す）
- MIDI はブラウザの無料 MIDI エディタ（例：Signal）や、無料の DAW（Windows なら Cakewalk by BandLab）で開いて直接いじってもよい

### ④ 似すぎチェック（私）
```
python3 tools/music/similarity.py 自作.mid 参考1_melody.mid 参考2_melody.mid ...
```
- 移調しても分かるよう「音程の動き＋リズム」で比べる。8 音以上そのまま一致＝高（書き直す）、5〜7 音＝中、それ以下＝低
- 結果は `docs/music/checks.md` に残す（後で説明できるように）

### ⑤ 音にする
**A. 音楽生成 AI（Suno など）**
- 有料プラン（商用利用に必要）を、作る月だけ契約。**生成した時点で有料プランだったことが商用の条件**なので、作る期間は解約しない
- 渡すもの：③のメロディ（wav を「音声のアップロード」機能で）、作者の歌詞、曲調の指示
- 曲調の指示の例（英語。作品名・作曲者名・歌手名は入れない）：
  `1970s Japanese anime opening theme, heroic march, full orchestra, brass fanfare, timpani, male choir, energetic, retro analog recording`
- 何十回も出して良いものを選ぶ。選んだ曲は②の analyze でメロディを抜き、④でもう一度チェック

**B. 無料の音源で自分たちで鳴らす**
- 無料の DAW ＋ 無料のオーケストラ音源（例：BBC Symphony Orchestra Discover）で、③の MIDI を鳴らす
- A で作った曲の「主題の旋律」だけ B で重ねて、メロディを確実に自分たちのものにする、という組み合わせもできる

### ⑥ 仕上げ
- ゲームのループ用に、曲の頭と終わりをつなぐ（私が波形を切って調整できる）
- `public/audio/bgm/` に置き、`config/game.ts` の BGM_CHOICES に足す。今の仮 BGM（GiantLOLO）は公開前に必ず差し替え

## 3. 曲のリスト（案）

主題歌のメロディ（モチーフ）を全曲で使い回す（ジャイアントロボ OVA と同じ考え方。曲数が少なくても統一感が出る）。

| 曲 | 使う所 | 雰囲気 | 主題の使い方 |
|---|---|---|---|
| 主題歌（歌あり） | タイトル・PV・ED | 昭和アニソン、マーチ、男声合唱 | そのまま |
| 区間 1 商店街 | プレイ | 軽快、木管と小太鼓 | サビの頭 4 小節を明るく |
| 区間 2 ビル街 | プレイ | 重厚、低音の弦と金管 | 短調に変えてゆっくり |
| 区間 3 航空公園 | プレイ | 壮大、合唱 | 全部を大きく |
| ボス（エネミービル） | ボス戦 | 緊迫、打楽器 | 主題を細かく刻む |
| 遅刻の危機 | 残り 1 分 | 速い、焦り | 主題を倍の速さで |
| クリア | 校門 | ファンファーレ | サビの最後 2 小節 |
| ED | エンディング | しみじみ、ピアノと弦 | 主題をゆっくり |
| リザルト・メニュー | メニュー | 軽い | 主題の伴奏だけ |
